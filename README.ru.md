## О проекте

[![en](https://img.shields.io/badge/lang-en-red.svg)](https://github.com/joyrexj4/laravel/blob/main/README.md)

Это курсовой проект, который был сделан весной 2026 на PHP и Laravel. Предметная область проекта представляет собой магазин музыкальных инструментов со следующим функционалом:
- Авторизация
- Просмотр товаров из БД
- Рабочая корзина
- Заказ продуктов (Запись в БД)
